# Ontario Analytics browser companion

The matching native Power BI report was verified in Desktop on 2026-10-16 and saved privately as PBIX. Native source and methodology: https://github.com/mamkon/Architecture_and_Data_Audit/tree/organize-ontario-powerbi/powerbi/ontario-analytics/native.

The public companion starts with synthetic demonstration values and invented PHU/region labels. It is not a live Power BI report. Use the file selector to open an authorized dataset JSON locally; the file is read in the browser, never uploaded or persisted. The privately delivered Browser-Data-PRIVATE.json uses the actual historical data. Do not commit that file to GitHub.

All three views include contextual storytelling and source-appropriate year selectors. Rates and medians are not summed; provincial rates remain separate from unweighted PHU medians. Original previews in this folder remain clearly labelled synthetic illustrations.
