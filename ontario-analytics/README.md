# Ontario Analytics portfolio companion

This self-contained interactive demonstration and its three preview PNGs use synthetic values and invented geographic labels only. They do not publish PHO/CIHI observations. The editable Power BI project, methodology, opening instructions and publication review are maintained at https://github.com/mamkon/Architecture_and_Data_Audit/tree/main/powerbi/ontario-analytics.

Open `index.html` directly or serve this folder. No API or credentials are used. The project link becomes available after the companion project pull request is merged. Native Power BI rendering is not established by these design previews.
